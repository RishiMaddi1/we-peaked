## GitHub Pages

This repo is meant to be served from **GitHub Pages** (branch `main`, folder `/`). After Pages is on, add your custom domain in:

**Repo → Settings → Pages → Custom domain**

Then at your domain registrar, point the domain at GitHub:

**Apex domain** (`yoursite.com`) — A records:

- `185.199.108.153`
- `185.199.109.153`
- `185.199.110.153`
- `185.199.111.153`

**www** — CNAME:

- `YOURUSER.github.io`

GitHub will also ask you to turn on **Enforce HTTPS** after the certificate is ready.
